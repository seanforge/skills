# Maintenance

1. Resolve and read every effective instruction chain; distinguish effective files from shadowed ones.
2. Compare instructions with code, configuration, and current policy sources. Preserve unrelated edits.
3. Keep current instructions; update stale details; move misplaced rules; remove only obsolete, duplicated, non-consequential, or user-authorized content.
4. Preserve and report consequential policy that cannot be verified; never replace it with a guess.
5. Keep concise mandatory rules and small essential context inline; link larger non-code context; remove anything code or configuration explains. Keep root `MUST-FOLLOW RULES` even when empty, and remove it from nested files with no local rule.
6. Validate links, scope, precedence, conflicts, and duplication.
