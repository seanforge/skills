# Maintenance

1. Resolve and read every effective instruction chain; distinguish effective files from shadowed ones.
2. Compare affected instructions with current code, configuration, and policy sources.
3. Keep valid instructions; update stale details; move misplaced rules; remove only proven obsolete, duplicated, non-consequential, or user-authorized content. Preserve and report unverifiable consequential policy.
4. Keep root `MUST-FOLLOW RULES` even when empty; remove it from nested files with no local rule. Validate links, scope, precedence, conflicts, and duplication.
